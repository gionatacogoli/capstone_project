# Capstone Project - ISTAT Traffic Analysis

Analisi degli incidenti stradali italiani per comune, 
realizzata come progetto finale del corso Boolean.

## Obiettivo
Identificare i comuni italiani con il più alto tasso 
di incidenti stradali, calcolando metriche per abitante 
e per km², per supportare decisioni di investimento 
in sicurezza stradale.

## Fonti dati
- API ISTAT: dati incidenti stradali per comune
- SITUAS ISTAT: popolazione e superficie per comune

## Tecnologie utilizzate
- Python (pandas, requests, matplotlib, seaborn, sklearn)
- Power BI
- GitHub
